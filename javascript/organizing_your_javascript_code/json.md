### Giới thiệu

JSON (JavaScript Object Notation) là một format được chuẩn hóa để cấu trúc dữ liệu. Nó dựa nhiều trên cú pháp của object trong JavaScript. Bạn sẽ thường gặp dữ liệu được format bằng JSON khi làm việc với server hoặc API bên ngoài - về cơ bản, đây là format phổ biến để truyền dữ liệu trên web.

May mắn là ở đây không có nhiều điều cần học. Chúng tôi chỉ đưa vào một bài về nó vì một số quy tắc format có thể gây nhầm lẫn nếu bạn không biết chúng. Hãy dành 10-15 phút xem qua các tài nguyên sau là bạn sẽ có thể bắt đầu.

### Tổng quan bài học

Phần này trình bày khái quát các chủ đề bạn sẽ học trong bài này.

- Tìm hiểu JSON là gì.
- Hiểu cách đọc và ghi dữ liệu được format bằng JSON.
