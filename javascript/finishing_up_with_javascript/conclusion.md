### Kết thúc khóa học JavaScript!

Hoàn thành khóa học JavaScript là một cột mốc lớn! Xin chúc mừng! Bạn đã học được nhiều khái niệm quan trọng của JavaScript như prototypes, closures, promises và event loops. Hãy dành một chút thời gian để nhìn lại chặng đường bạn đã đi qua.

Đến lúc này, bạn có thể tạo ra các frontend mạnh mẽ và linh động chỉ bằng JavaScript thuần. Tuy nhiên, phần frontend vẫn chưa kết thúc. Trong các khóa học sắp tới, bạn sẽ học về accessibility, responsive design và [React](https://react.dev/), một thư viện dùng để tạo các giao diện. Bạn đã từng trải qua khó khăn khi phải cập nhật DOM thủ công theo những thay đổi của dữ liệu bên dưới, và đó là nơi React đơn giản hóa quy trình này.
